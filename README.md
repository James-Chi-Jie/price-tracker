# 京东低价预警（本地浏览器版）

这是 Chrome Manifest V3 扩展原型：在本地浏览器中每 30 分钟搜索京东商品关键词，根据你定义的商品类型规则匹配 SKU，当价格从“未低于阈值”变成“低于阈值”时发送桌面通知。

## 使用方式

1. 打开 Chrome 的 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`jd-price-alert-extension`。
5. 点击扩展图标，输入商品关键词和目标价格，点击“搜索并选择商品”。
6. 在选择页勾选一个或多个代表性商品，确认或修改“必含关键词”和“排除关键词”，点击“按此类型创建监控”。
7. 保持 Chrome 开启，并让电脑不要进入睡眠。

## 当前范围

- 支持京东商品关键词搜索，并可从代表性商品生成可编辑的类型匹配规则。
- 默认每 30 分钟检查一次。
- 新建任务按匹配规则发现所有符合的 SKU，并按 SKU 记录状态：低于阈值时只提醒一次；价格回升后再次跌破阈值会再次提醒。
- 勾选的商品只是代表性样本；真正的监控范围由“必含关键词”和“排除关键词”决定。
- 通知中展示低价商品，点击通知可以打开最低价商品页面。
- 价格无法确认、页面加载失败或遇到验证页面时，不会误报。
- 当前没有处理优惠券、会员价、地区价和复杂规格选择。
- 当前读取京东搜索结果的第一页。
- 当前匹配规则只作用于搜索结果第一页；没有出现在第一页的相似 SKU 不会被发现。
- 旧版创建的任务没有类型匹配规则，仍会按照旧逻辑运行；建议删除后按新流程重新创建。

## 扩展平台

后台调度、阈值判断、状态保存和通知都是平台无关的。新增平台时，增加对应的 `platforms/<platform>.js`、搜索 URL 构造和页面结果读取逻辑即可。
