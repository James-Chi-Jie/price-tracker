# 京东低价预警（本地浏览器版）

这是 Chrome Manifest V3 扩展原型：在本地浏览器中每 30 分钟搜索京东商品关键词，根据你定义的商品类型规则匹配 SKU，当价格从“未低于阈值”变成“低于阈值”时发送桌面通知。

## 使用方式

1. 打开 Chrome 的 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`jd-price-alert-extension`。
5. 点击扩展图标，输入商品关键词，点击“搜索商品并设置规则”。
6. 在选择页设置价格计算方式，再选择剂型、规格/浓度和盒数等选项，必要时填写排除词；如果选择了多个盒数，可以分别填写每个盒数的目标价格，最后点击“按这些条件创建监控”。
7. 保持 Chrome 开启，并让电脑不要进入睡眠。

## 给同事使用

推荐发布到 Chrome Web Store，并将可见性设置为“未列出（Unlisted）”。这样同事只需要打开你分享的商店链接，点击“添加至 Chrome”，不需要下载代码或开启开发者模式。

发布流程：

1. 将本目录压缩成 ZIP，压缩包根目录必须直接包含 `manifest.json`。
2. 登录 Chrome Web Store Developer Dashboard，上传 ZIP。
3. 在 Distribution/分发设置中选择 Unlisted/未列出，完成审核后复制商店链接。
4. 把商店链接发给同事；以后升级时递增 `manifest.json` 的版本号并重新上传，审核通过后 Chrome 会自动更新。

临时测试也可以把 ZIP 解压后，在 `chrome://extensions/` 开启“开发者模式”，选择“加载已解压的扩展程序”，但这不适合作为正式分发方式。

本扩展的数据和定时任务保存在每个人自己的浏览器里，同事需要在自己的 Chrome 中单独创建监控，并保持 Chrome 和电脑运行；当前版本不会把监控任务同步给其他人。

## 当前范围

- 支持京东商品关键词搜索，并可从本次结果中选择结构化变体条件。
- 默认每 30 分钟检查一次。
- 新建任务按匹配规则发现所有符合的 SKU，并按 SKU 记录状态：低于阈值时只提醒一次；价格回升后再次跌破阈值会再次提醒。
- 勾选的商品只是代表性样本；真正的监控范围由“必含关键词”和“排除关键词”决定。
- 支持剂型、剂量规格、单包装数量和盒数规则；例如可以区分 2g·6袋 与 2g·10袋。
- 支持按总价、平均每盒价格或平均每个单位价格比较阈值。
- 支持按完整规格组合分别设置目标价格，例如 2g·6袋低于 200 元、2g·10袋低于 300 元；每个组合会使用自己的阈值。
- 选择剂型、剂量规格、单包装数量或盒数后，下方商品预览和链接会同步收窄到符合条件的结果。
- 选项数量按当前筛选组合联动计算；如果两个选项没有交集，会明确显示“当前组合无匹配”，不会生成无效的目标价格规则。
- 通知中展示低价商品，点击通知可以打开最低价商品页面。
- 监控列表可展开查看最近一次匹配到的商品链接，并导出 CSV。
- 价格无法确认、页面加载失败或遇到验证页面时，不会误报。
- 当前没有处理优惠券、会员价、地区价和复杂规格选择。
- 当前读取京东搜索结果的前 3 页，并按 SKU 去重。
- 当前匹配规则只作用于搜索结果前 3 页；没有出现在前 3 页的相似 SKU 不会被发现。
- 规格解析依赖商品卡片文本；会扫描商品卡片中的标题和规格信息，优先识别包装规格中的剂量和单包装数量，并排除“100%正品/好评”等百分号营销文案。如果卡片没有写清盒数或单位数量，按每盒/每单位比较时会跳过该商品。
- 旧版创建的任务没有类型匹配规则，仍会按照旧逻辑运行；建议删除后按新流程重新创建。

## 扩展平台

后台调度、阈值判断、状态保存和通知都是平台无关的。新增平台时，增加对应的 `platforms/<platform>.js`、搜索 URL 构造和页面结果读取逻辑即可。
