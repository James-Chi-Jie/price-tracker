# 京东低价预警（本地浏览器版）

这是 Chrome Manifest V3 扩展原型：在本地浏览器中每 30 分钟搜索京东商品关键词，当搜索结果中的商品价格从“未低于阈值”变成“低于阈值”时发送桌面通知。

## 使用方式

1. 打开 Chrome 的 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`jd-price-alert-extension`。
5. 点击扩展图标，添加商品关键词和目标价格。
6. 保持 Chrome 开启，并让电脑不要进入睡眠。

## 当前范围

- 支持京东商品关键词监控。
- 默认每 30 分钟检查一次。
- 每个商品按京东 SKU 记录状态：低于阈值时只提醒一次；价格回升后再次跌破阈值会再次提醒。
- 通知中展示低价商品，点击通知可以打开最低价商品页面。
- 价格无法确认、页面加载失败或遇到验证页面时，不会误报。
- 当前没有处理优惠券、会员价、地区价和复杂规格选择。
- 当前读取京东搜索结果的第一页。

## 扩展平台

后台调度、阈值判断、状态保存和通知都是平台无关的。新增平台时，增加对应的 `platforms/<platform>.js`、搜索 URL 构造和页面结果读取逻辑即可。
